## 4. 🔬 분석 과정 (가설 → 분석 → 인사이트)

### Step 1. 데이터 수집 & 크롤링
- **WHY**: 단일 채널은 편향된 목소리. 교차 검증 가능한 **멀티채널 데이터셋** 필수.
- **HOW**: Python(`BeautifulSoup`, `Selenium`, `Scrapy`) 기반 채널별 크롤러.

### Step 2. 데이터 정제 & 전처리
- **WHY**: 광고·봇·중복을 제거해야 분석 신뢰성 확보.
- **HOW**: 2,400개 → **800개 핵심 유효 표본**으로 정제, 브랜드 표기 통일.

### Step 3. EDA + CatBoost 회귀분석
- **가설**: *"노트북 리뷰 수는 CPU·GPU 등 성능 스펙에 비례할 것이다."*
- **HOW**: EDA로 변수 간 관계 탐색 → **CatBoost 회귀분석**으로 변수 중요도 산출.
- **🔥 가설 반전 결과**:
  - CPU 성능 → 리뷰 수와 **약한 연관만 존재**
  - 외장GPU → 있는 경우에만 리뷰 집중 (비선형)
  - RAM → 인기 제품 효과로 비선형 영향
  - **📌 결론: 리뷰 수는 단일 성능 지표로 결정되지 않는다. 성능보다 가격·휴대성·사용성이 더 큰 영향을 미친다.**

### Step 4. K-Means 클러스터링 (k=6)
- **가설**: *"노트북 시장은 가격·성능·무게 기준으로 명확히 세그먼트화될 것이다."*
- **HOW**: 스펙·가격·리뷰 데이터를 벡터화 → K-Means(k=6)로 **6개 소비자 세그먼트** 도출.

### Step 5. Gemini API 기반 리뷰 심화 분석
- **HOW**: **Gemini API**로 LLM 기반 리뷰 감성분석·핵심 키워드 추출·광고성 리뷰 필터링.
- **WHY Gemini**: 한국어 구어체·커뮤니티 은어까지 포착해 룰베이스 대비 정확도 향상.

### Step 6. 인사이트 도출 & 캠페인 설계
- **WHY**: 분석이 "보고서"로 끝나면 의사결정에 쓰이지 못한다. **바로 실행 가능한 캠페인**으로 가공.

## 5. 💡 핵심 인사이트 (Marketing Perspective)

### 🔎 Insight 1. "성능 스펙 ≠ 소비자 선택" — 구매 결정 요인 재정의
**CatBoost 회귀분석 결과, 리뷰 수(시장 반응)에 영향을 미치는 요인은 성능 스펙이 아니었다.**
- 구매 결정 요인: **가격 92%, 무게 78%** > 성능 지표
- **📌 마케팅적 함의**: LG 그램의 Hero Message를 "성능"에서 **"가볍다 × 합리적 가격"** 중심으로 재정렬해야 한다.

### 🔎 Insight 2. Cluster 4가 LG 그램의 전략적 거점
**K-Means(k=6) 결과, 6개 세그먼트 중 "경량 보급형" 세그먼트가 LG의 핵심 타깃으로 식별됨.**

| 클러스터 | 특징 | 제품 수 | 평균가격 | 무게 | 별점 |
|---|---|---|---|---|---|
| C0 · 고성능 프리미엄(윈도우) | 외장GPU+AI칩 100% | 144개 | 309만원 | 2.23kg | **2.99 (최저)** |
| C1 · 리뷰 없는 보급형 | 외장GPU 0%, 리뷰 거의 0 | 176개 | 204만원 | 1.44kg | — |
| C2 · 고성능 비AI(윈도우) | GPU 100%/AI 0% | 180개 | 270만원 | 2.37kg (최대) | — |
| C3 · 고성능 프리도스 | — | 135개 | — | — | **4.41 (우수)** |
| **★ C4 · 경량 보급형** | **LG 핵심 타깃** | **154개** | **198만원** | **1.43kg** | **4.79 (최고)** |
| C5 · 고성능 프리미엄(프리도스) | — | 74개 | — | — | — |

**Cluster 4의 4대 강점 지표**
- 💰 **198만원** — 최저 평균가격 (가격 경쟁력 최상)
- 🪶 **1.43kg** — 최경량 무게 (초경량 세그먼트)
- ⭐ **별점 4.79** — 소비자 만족도 1위
- 📊 **SKU 점유율 42.2%** — LG 전략 집중 구간

> 📌 **마케팅적 함의**: Cluster 4는 **가격·무게·만족도 3박자가 맞는 골든 세그먼트**. 다만 **삼성과의 경쟁 압력이 가장 강한 구간**이기도 하므로, 차별화 USP 확보가 필수.

### 🔎 Insight 3. LG만의 차별화 USP: "에어로미늄 × 그램 스케일링"
- **물리적 강점**: **에어로미늄(Aeromanium)** 항공우주 소재 → "가벼움 + 견고함" 동시 충족
- **서비스 강점**: **그램 스케일링 서비스** → 내부 팬 전문 관리 = 장기 신뢰성
- **📌 마케팅적 함의**: 스펙 경쟁(삼성)·생태계 경쟁(애플)에서 밀리는 대신, **"소재 × 서비스"** 라는 LG만의 축으로 포지셔닝 재구성.

### 🔎 Insight 4. 유튜브가 구매 퍼널의 핵심 레버
- **소비자의 58%가 유튜브로 성능 검증** 후 구매 결정
- **📌 마케팅적 함의**: 단순 광고가 아닌 **실증 콘텐츠** (스크래치 테스트·스케일링 before/after)로 신뢰 구축이 가장 효율적.

1. **"가설 반전"이 있는 분석** — *"성능 스펙이 리뷰를 결정할 것"* 이라는 초기 가설을 CatBoost로 반박하고, **가격·무게가 진짜 동인**임을 실증.
2. **분석 → 전략 → 캠페인 풀 퍼널 설계** — 보고서로 끝나지 않고 **팝업 스토어 4존 체험 + 유튜버 협업 + 도달 75만 설계**까지 실행 단위로 연결.
3. **데이터와 현장 감각의 결합** — 오프라인 판매 경험(무인양품·GS25)이 Cluster 4 해석의 결정적 시각을 제공. **데이터 너머 소비자를 읽는 능력** 증명.
4. **클러스터링으로 "전략 거점"을 직접 발굴** — 단순 분석이 아니라 K-Means(k=6)로 6개 세그먼트를 도출하고, **Cluster 4(SKU 42.2% · 별점 4.79)** 를 LG의 핵심 타깃으로 식별·전략화.
5. **멀티채널 × 멀티모델 구조** — 다나와·유튜브·네이버·커뮤니티 4축 데이터를 **회귀(CatBoost) + 군집(K-Means) + LLM(Gemini)** 으로 삼각 검증.
6. **USP의 본질 재정의** — 스펙 경쟁(삼성)·생태계(애플) 대신, **"에어로미늄 × 그램 스케일링"** 이라는 LG만의 소재·서비스 축을 발굴.
